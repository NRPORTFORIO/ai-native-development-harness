# 🤖 ai-native-development-harness
### ソフトバンク株式会社「AI駆動開発／開発変革エンジニア」特化型ポートフォリオ

本プロジェクトは、ソフトバンク株式会社の「開発組織におけるAI Native化」および「ハーネス／ループエンジニアリングの検証・仕組み化」という最先端のミッションに100%特化し、実務未経験の立場から一から構築した**「自律型AI開発エージェントの制御・自動検証フレームワーク」**です。

普段はスマートフォン（Pythonista3）中心の環境であることを最大限に活かし、「限られたデジタルリソースと生成AI（開発パートナー）を客観的に組み合わせ、前例のないテーマを小さく試して実用化する」という、貴部門が求める**AI駆動開発の実効性と実行力**を証明する成果物です。

---

## 📌 プロジェクトの核（コアアセット）

本ポートフォリオは、AI駆動開発の安全性を高め、夜間自動開発（自律開発）を成功させるための2つのアセットで構成されています。

### 1. 📝 Agent.md（AIエージェント行動ルール設定ファイル）
AIエージェント（DevinやClaude Code等）が人間の指示を無視して暴走したり、セキュリティ脆弱性のあるコードを出力したりするのを未然に防ぐための、プロジェクトルート配置用の厳格なシステム指示書（Markdown）です。

*   **ガードレールの設置:** APIキーのハードコード禁止、未承認外部ライブラリの自動インストール制限の定義。
*   **ループエンジニアリングの命令:** テスト失敗時にAI自身がエラーログを高速にパースし、最大3回まで自律的に原因特定とコード修正の「自己修正ループ」を回す指示の構造化。

### 2. 🐍 ai_log_analyzer.py（AI出力自動パース・検証スクリプト）
上記「Agent.md」のルールをAIが本当に守っているか、夜間自動開発のログをリアルタイムにパース（解析）して異常や暴走の予兆を検知するPythonスクリプトです。スマートフォン（Pythonista3）上で実証・動作検証を行っています。

*   **ログの高速自動パース:** `re`（正規表現）モジュール等を用い、大量のテキストログから「CRITICAL」「WARNING」をミリ秒単位で抽出。
*   **セーフティシャットダウン:** セキュリティ規約違反（APIキー漏洩の兆候など）を検知した際、自動開発タスクを安全に強制終了させるアラート機能を実装。

## 📊 開発環境・スキルレベル

| 構成要素 | 使用言語・ツール | 役割・実装内容 |
| :--- | :--- | :--- |
| **開発ルール定義** | Markdown (`Agent.md`) | AIエージェントのペルソナ定義、自己修正ループの回数制限、セキュリティガードレール |
| **自動化・検証** | Python 3.x (`re`, `datetime`) | テキストログの高速パース、CRITICALログ検知による自動アラート・強制終了ロジック |
| **実証・検証環境** | Pythonista3 / Wandbox | モバイル環境およびWebコンパイラを駆使した、自律的な開発インフラの工夫と実行 |
| **AI共創パートナー** | 生成AI（ChatGPT / Claude等） | プロンプトエンジニアリングによる仕様設計・コードの脆弱性検証の壁打ち |

## 🚀 本成果物が貴部門の「必須条件」を満たす理由

1.  **AI駆動開発の生産性向上への挑戦:** 
    ただAIにコードを書かせるのではなく、AIの「開発生産性を管理・制御する側」の視点（Skills/Agentアセットの整備）を個人レベルで具現化しています。
2.  **小さく試して実用化する実行力:** 
    パソコンがないという制約を言い訳にせず、スマホ環境で動作するログアナライザーを自力で調査・開発し、GitHubへ一般公開（実用化）までやり遂げました。
3.  **ビジネス・コスト感覚との掛け合わせ:** 
    日商簿記2級（原価計算・工業簿記）の知識を活かし、「AIの自律開発による人件費削減」と「エラー暴走によるインフラコスト（クラウドの無駄遣い）の防止」を客観的に見据えた設計思想を取り入れています。
